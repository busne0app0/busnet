## 🏛 ЧАСТИНА 1. КАРТА ПРОЕКТУ ТА АРХІТЕКТУРА ДОДАТКУ

### 1.1. Як влаштована екосистема додатку
`BUSNET CONNECT` функціонує як **автономний повноцінний веб-додаток (Standalone Web App)** усередині загального монорепозиторію.
- **Маршрут додатку**: `/connect`
- **Маршрут окремої публікації (SEO & Social Cards)**: `/connect/post/:slug`
- **Зв'язок із кабінетом квитків**: кнопка `[ ← До квитків ]` у шапці повертає користувача в `/dashboard`, а з кабінету пасажира веде інтерактивна плашка `ConnectPromoCard`.
- **Авторизація**: спільна з основним сайтом через `useAuthStore` (Supabase Auth). Авторизований пасажир автоматично стає повноправним користувачем соцмережі.

### 1.3. Взаємозв'язки між компонентами та базою даних

1. **Завантаження стрічки**:
   `ConnectApp.tsx` викликає `useConnectStore.initConnect()` ➔ спрацьовує `connectFeedService.fetchPosts()` ➔ виконується запит `supabase.from('forum_posts').select('*').eq('is_public', true)` ➔ пости мапляться через `mapRowToConnectPost()` і потрапляють у `CommunityView.tsx`.
2. **Створення публікації**:
   Користувач тисне центральний `[+]` у нижньому барі ➔ відкривається `CreatePostModal.tsx` ➔ дані йдуть у `useConnectStore.createPost()` ➔ `connectFeedService.createPost()` формує безпечний payload без системних колонок ➔ тригер бази даних присвоює `user_id` з `auth.uid()`, генерує SEO-слаг `slugify_uk()` та перевіряє ліміт 60 секунд ➔ запускається клієнтський таймер зворотного відліку.
3. **Вподобайки (Likes)**:
   Клік по сердечку в `PostCard.tsx` ➔ `useConnectStore.likePost()` перевіряє авторизацію (якщо гість — просить увійти) ➔ робить миттєвий оптимістичний апдейт цифри ➔ викликає `connectFeedService.likePost()` через RPC `increment_likes` ➔ отримує точні дані з бази.
4. **Коментарі**:
   Клік по іконці коментаря відкриває `CommentsDrawer.tsx` ➔ підключається Supabase Realtime канал `comments-${postId}` ➔ нові коментарі з'являються миттєво без перезавантаження сторінки ➔ тригер бази автоматично збільшує `forum_posts.comments`.
5. **Профіль у стилі Instagram**:
   `ProfileView.tsx` бере юзера з `useAuthStore` ➔ виводить статистику, біографію, соцмережі (Instagram, Telegram, Web) ➔ розділяє дописи на публічні, приватні чернетки та збережені закладки (з `localStorage`). Редагування форми викликає `useAuthStore.updateUserProfile()`, що оновлює рядок у таблиці `users`.
6. **Соціальні роботи (Telegram, Facebook, Viber, WhatsApp)**:
   При відправці посилання `https://busnetua.it/connect/post/<slug>` у чат Telegram/Facebook запит перехоплюється `vercel.json` та `api/connect-prerender.ts` ➔ за мілісекунди віддається легкий HTML із правильними `og:title`, `og:image`, `og:description` та Schema.org ➔ у чаті виникає велика красива прев'ю-картка.

## 🛠 ЧАСТИНА 3. ПОСІБНИК ЗМІН: ЯК САМОСТІЙНО ПРАВИТИ КОД

### 1. Як змінити назви або іконки нижнього бару
Відкрий файл:
`packages/shared/src/connect/components/ConnectAppLayout.tsx`
Знайди блок `<nav className="fixed bottom-0 ...">`. Тут розташовані 5 кнопок:
- Стрічка (`community`)
- Пошук (`discover`)
- Створити (`[+]`)
- Чат (`messages`)
- Профіль (`profile`)
Ти можеш змінити напис, замінити іконку з бібліотеки `lucide-react` або поміняти їхній порядок.

### 2. Як змінити або додати нові категорії публікацій
1. Відкрий `packages/shared/src/connect/types/connect.types.ts`:
   Додай нову назву в масив `CONNECT_POST_TYPES` (наприклад, `'hotel'`).
2. Відкрий `packages/shared/src/connect/components/CreatePostModal.tsx`:
   У масиві `types` додай `{ id: 'hotel', label: 'Житло / Готелі', icon: Home }`.
3. Відкрий `packages/shared/src/connect/components/PostCard.tsx`:
   У функції `getTypeBadge` додай кольори та бейдж для нової категорії.

### 3. Як змінити дизайн картки або кольори неону
Усі кольори використовують утиліти Tailwind CSS:
- Фон сторінки: `#060a12`
- Фон карток: `#0c1424`
- Неоновий акцент: `cyan-400`, `blue-500`
- Тексти: `text-white`, `text-slate-300`, `text-slate-400`
Якщо хочеш зробити фіолетовий або смарагдовий акцент замість бірюзового — заміни `cyan-500` на `emerald-500` або `violet-500`.

### 4. Як перевірити код перед відправкою
У терміналі завжди виконуй:
```bash
npx vite build apps/landing
```
Якщо в кінці написано `built in ...s` зеленим кольором і 0 помилок — сміливо роби пуш на Vercel!
