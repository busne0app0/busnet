### 1.2 Де знаходиться дизайн та стилістика
Кабінет побудований на **Tailwind CSS v4** з неоновою Dark Cyber-Logic естетикою:
1. **Глобальні змінні теми:** `packages/shared/src/index.css`
   - Кольори: `--color-neon-cyan: #00D4FF`, `--color-neon-violet: #8B5CF6`, `--color-neon-emerald: #10B981`, `--color-neon-gold: #F59E0B`.
   - Фонові градієнти: `#050B14`, `#0B1221`, картки `#1A2639]/30`.
   - Шрифти: `Inter`, `Syne`, `DM Sans`.
2. **Точкові стилі сторінок:** Знаходяться безпосередньо у JSX-розмітці кожного файлу через Tailwind класи (`className="..."`).
3. **Анімації переходів:** Використовується бібліотека `framer-motion` (`<motion.div>`, `<AnimatePresence>`).

### 1. `CarrierLayout.tsx` — Каркас кабінету та навігація
- **Шлях:** `packages/shared/src/pages/carrier/CarrierLayout.tsx`
- **Призначення:** Базовий контейнер для всього кабінету. Залишається незмінним при перемиканні між сторінками.
- **Що всередині:**
  - **Десктопна плаваюча панель (Sidebar):** Знаходиться зліва (`<aside>`). Містить логотип Busnet, аватар компанії з кнопкою завантаження логотипу, чесний бейдж рейтингу, вертикальні іконки з кольоровим підсвічуванням та поповерами.
  - **Мобільна навігація + Bottom Sheet:** На телефонах показує нижню панель навігації (`<nav>`). При кліку на категорію відкривається модальна шторка з підпунктами.
  - **Мобільна верхня шапка (Top Bar):** Показує логотип, назву компанії, рейтинг і міні-аватар.
  - **Банери верифікації та блокування:** Автоматично показуються над сторінкою, якщо перевізник має статус `pending_verification` або `blocked`.
  - **Realtime індикатор сповіщень:** Червона точка біля іконки чату з кількістю нових сповіщень.
- **Як редагувати дизайн:**
  - Пункти меню та їхні кольори/іконки: масив `MENU_CATEGORIES` на початку файлу.
  - Ширина/висота бічної панелі: тег `<aside>` (класи `w-[90px]`, `rounded-[32px]`, `bg-[#0B1221]/80`).

### 2. `CarrierDashboard.tsx` — Головна панель керування
- **Шлях:** `packages/shared/src/pages/carrier/CarrierDashboard.tsx`
- **Призначення:** Аналітичний центр операційної діяльності перевізника за останній тиждень та місяць.
- **Що всередині:**
  - **Карточки метрик (KPI):**
    - Дохід за 7 днів (з графіком продажів).
    - Пасажиропотік за поточний місяць.
    - Активні рейси (кількість активних шаблонів маршрутів).
    - Рейтинг на основі реальних відгуків (`reviews`).
  - **Швидкі дії:** Кнопка «Створити рейс», «Завантажити розклад».
  - **Блок "Активні маршрути":** Таблиця актуальних рейсів з кнопками «Редагувати» (перехід в `NewTrip` з предзаповненням форми) та видалення.
  - **AI-рекомендації:** Розумні підказки щодо оптимізації маршрутів на основі попиту.
- **Як редагувати дизайн:**
  - KPI блоки: шукайте блок `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4`.
  - Графік виручки: компонент `ResponsiveContainer` / `AreaChart`.

### 3. `NewTrip/` — Конструктор маршрутів
- **Папка:** `packages/shared/src/pages/carrier/NewTrip/`
- **Основний файл:** `NewTrip.tsx` (понад 1400 рядків)
- **Допоміжні файли:**
  - `constants.ts` — списки зручностей, правила, дефолтні значення.
  - `hooks.ts` — автозбереження чернетки в `localStorage`, валідація колізій.
  - `types.ts` — типізація стану маршруту, зупинок, цін.
  - `utils.ts` — генератори ID, розрахунок інтервалів, парсинг тексту розкладу (Smart Parser).
- **7 Кроків конструктора:**
  1. *Основне:* Назва, перевізник, кількість місць, зручності (Wi-Fi, туалет тощо), чи є пересадка.
  2. *Графік зупинок:* Зупинки туди (`outbound`) та назад (`inbound`), час, адреси автостанцій.
  3. *Регулярність:* Дні тижня відправлення або конкретні дати.
  4. *Тарифи & Ціни:* Цінова матриця між усіма парами міст (`A -> B`, `A -> C`, `B -> C`), дзеркальні ціни, валюта (ГРН для UA, EUR для Європи).
  5. *Правила & Знижки:* Багаж, тварини, дитячі/студентські знижки.
  6. *Попередній перегляд:* Віртуальний квиток, схема рейсу, експорт у PDF.
  7. *Фініш:* Кнопки «Зберегти як чернетку» (`draft`) та «Відправити на перевірку» (`pending`).
- **Як редагувати дизайн:**
  - Кожен крок знаходиться у секції `{currentStep === 1 && ...}` до `{currentStep === 7 && ...}`.
  - Нижня панель кнопок: тег `<footer>` в кінці файлу.

### 4. `Schedule.tsx` — Розклад та управління рейсами
- **Шлях:** `packages/shared/src/pages/carrier/Schedule.tsx`
- **Призначення:** Список усіх рейсів компанії, фільтрація за статусами, модальне вікно перегляду та тарифікація.
- **Що всередині:**
  - **Вкладки статусів:** «ВСІ», «АКТИВНІ», «ЧЕРНЕТКИ», «МОДЕРАЦІЯ», «СКАСОВАНІ».
  - **Таблиця рейсів:** Назва рейсу, міста сполучення, регулярність (дні тижня), діапазон цін (з підтримкою AL-TRANS API та матриць `pricing.ts`), статус рейсу.
  - **Дії з рейсом:**
    - Кнопка «Око» — модальне вікно `RouteViewModal` з графіком зупинок та тарифами.
    - Кнопка «Олівець» — редагування рейсу у `NewTrip`.
    - Кнопка «Хрестик» — скасування/архівація маршруту.
- **Як редагувати дизайн:**
  - Карточки та таблиця: шукайте тег `<table>` та мобільний вигляд рейсів у блоці `md:hidden`.

## 3. Допоміжні модулі та хуки (Під капотом)

1. **`packages/shared/src/lib/pricing.ts`**:
   - Головний ціновий рушій.
   - Шукає ціни між зупинками за форматом `id|id`, `i-j`, та старими цінами зупинок.
   - Безпечно парсить числові рядки (`"45"`, `50.5`).
   - Підраховує мінімальну/максимальну ціну рейсу та покриття тарифів (наприклад, `3/3 пар`).
   - Форматує валюту: `ГРН`, `EUR`, `$`, `PLN`.

2. **`packages/shared/src/hooks/useCarrierRating.ts`**:
   - Єдине джерело правди про рейтинг перевізника.
   - Підключається через Supabase Realtime до таблиці `reviews` і повертає `{ avg: 4.9, count: 12 }`. Якщо відгуків 0, повертає `count: 0`.

3. **`packages/shared/src/lib/carrierLogo.ts`**:
   - Безпечне завантаження логотипів.
   - Перевіряє дозволені MIME-типи (`PNG`, `JPEG`, `WebP`) та обмеження у 2 МБ.
   - Зберігає у персональну папку `${uid}/logo-${Date.now()}.${ext}`.
   - Видаляє старий аватар зі сховища Supabase Storage при заміні.

4. **`packages/shared/src/types/index.ts`**:
   - Головний файл типізації TypeScript для всього проекту (`Route`, `Trip`, `Stop`, `Booking`, `User`).

## 4. Як самостійно редагувати сторінки: Швидка інструкція

1. **Хочете змінити колір або шрифт елемента:**
   - Відкрийте потрібний файл сторінки (`.tsx`).
   - Знайдіть відповідний тег (наприклад, `<button>`, `<div>` або `<h1>`).
   - У атрибуті `className` змініть колір тексту (наприклад, `text-[#00E5FF]` на `text-amber-400`) або фон (наприклад, `bg-[#0B1221]` на `bg-slate-900`).
2. **Хочете додати новий пункт або колонку в таблицю:**
   - Знайдіть блок `<thead><tr>...</tr></thead>` та додайте `<th>Ваша колонка</th>`.
   - У секції `<tbody>` знайдіть мапінг рядків `data.map(item => (...))` та додайте `<td>{item.новий_параметр}</td>`.
3. **Хочете змінити текст або підпис:**
   - Усі текстові підписи знаходяться відкрито прямо в JSX компонентах українською мовою. Просто змініть потрібне слово чи речення.
4. **Хочете додати нову сторінку до кабінету:**
   - Створіть новий файл у `packages/shared/src/pages/carrier/MyNewPage.tsx`.
   - Зареєструйте маршрут у `apps/carrier/src/App.tsx`: `<Route path="mynewpage" element={<MyNewPage />} />`.
   - Додайте пункт меню у масив `MENU_CATEGORIES` у `CarrierLayout.tsx`.
